# wirdlink-resources

Les chemins ci-dessous sont relatifs à la racine du dépôt WirdLink.

Lire docs/ressources.md. Consulter les sources avec les connecteurs disponibles et suivre les skills Figma requis par les opérations choisies. Consigner date, document ou nœud exact et niveau de lecture. Distinguer exigences confirmées, observations visuelles et propositions. Les métadonnées Figma seules ne suffisent pas à implémenter fidèlement un écran. Si une source est inaccessible, conserver son lien et indiquer la limite. Actualiser le registre local sans modifier les documents distants hors demande.

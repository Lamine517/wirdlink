# Décisions d'architecture

Créer un fichier numéroté, par exemple `0001-choix-backend.md`, à partir de `modele.md`.
Distinguer « proposé », « accepté » et « remplacé ». Une proposition ne sélectionne pas un fournisseur.
Lier les exigences sources et consigner les conséquences avant l'implémentation structurante.

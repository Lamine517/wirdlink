# WirdLink — consignes pour Claude Code

Lire et suivre `AGENTS.md` à la racine, puis `CONVENTIONS.md`.
Ces fichiers sont la référence commune aux assistants de ce dépôt.

Les agents spécialisés sont dans `.claude/agents/` ; leur répartition et leurs
exemples d'utilisation figurent dans `docs/agents/README.md`.
Les procédures réutilisables sont dans `docs/skills/` : lire le `SKILL.md`
concerné explicitement lorsque la découverte automatique n'est pas disponible.

L'ancien exemple Solalma est conservé dans `docs/reference-claude-solalma.md`
uniquement comme archive. Ses commandes, sa stack et ses exigences ne s'appliquent pas à WirdLink.

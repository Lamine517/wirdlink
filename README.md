# WirdLink

Application Angular pour créer et partager des wirds. Premier parcours participant
fonctionnel avec données de démonstration et sauvegarde locale.

```sh
npm ci
npm start
```

Ouvrir http://localhost:4200. Chrome est nécessaire aux tests :

```sh
npm run test:coverage
npm run build
```
